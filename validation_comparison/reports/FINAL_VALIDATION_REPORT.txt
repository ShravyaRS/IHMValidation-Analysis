================================================================================
PRECISION FIX
================================================================================

FreeSAS's LROH.probaLongerRun() uses float64 arithmetic for the
Schilling (1990) recursion. On some platforms (Python 3.13 / NumPy 2.4),
this accumulates rounding errors for large n.

Example - SASDBD9_FIT_728 (n=543, C=11):
  DATCMP:                  p = 0.230925
  FreeSAS (raw float64):   p = 0.230548  (error = 0.000377)
  Exact Decimal fix:       p = 0.230925  (error = 0.000000)
  Schilling analytical:    p = 0.230925

This pipeline uses Python's Decimal module (precision=100) to
recompute the p-value after obtaining N and C from FreeSAS's gof().
This eliminates all floating-point error in the probability calculation.

================================================================================
DATA EXTRACTION
================================================================================

Data is extracted from the _sas_model_fitting loop in each .sascif file:
  _sas_model_fitting.momentum_transfer  -> q
  _sas_model_fitting.intensity          -> I_exp (on the fit grid)
  _sas_model_fitting.fit                -> I_fit

No rebinning or interpolation is applied. Uniform sigma = 1.0 is used
(sigma does not affect the CorMap p-value calculation).

Filter: q > 0 only. Rows with I_exp = 0 are retained.
