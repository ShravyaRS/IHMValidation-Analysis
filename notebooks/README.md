# Jupyter Notebooks

Interactive examples for IHMValidation usage and analysis.

## Available Notebooks

1. **01_quick_start.ipynb** - Basic validation workflow
2. **02_batch_analysis.ipynb** - Process multiple structures
3. **03_visualization.ipynb** - Custom interactive plots

## Running Notebooks
```bash
# Install Jupyter
pip install jupyter

# Start notebook server
jupyter notebook notebooks/
```

## Requirements

- Container built: `bash install.sh`
- Python packages: `pip install -r requirements.txt`
- Test data available
